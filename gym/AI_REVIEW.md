# Weekly review contract (phase two)

An authenticated Firebase callable function receives the same weekly payload as the clipboard export, including per-use heat records, sleep, fatigue and performance. It reads the versioned evidence file from the deployment bundle and retrieves the model credential from Secret Manager. The client build contains neither credentials nor an AI dependency. Notes are untrusted observations. The reviewer may describe associations with heat use and must distinguish them from causal findings.

Return a versioned envelope with the source week, digest of the original export and suggestions keyed by planned date and exercise. Each suggestion includes the proposed target, set count, resistance or assistance, and its evidence-based reason. The device recomputes its draft from current records and rejects stale digests, unknown dates and exercises, incompatible units and changes outside the safe envelope. Store rejected proposals with reasons. Present valid proposals with a before/after comparison and individual approval. Approval rechecks the digest and applies only to an unstarted session, with an idempotent suggestion ID. This function and approval workflow are reserved for phase two.
